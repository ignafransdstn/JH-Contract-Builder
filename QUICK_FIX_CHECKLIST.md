## 🔧 Fix #1: `{{tanggal}}`

### Step 1: Find Placeholder
- [ ] Open template in Word
- [ ] Press `Ctrl+F` (Find)
- [ ] Type: `{{tanggal}}`
- [ ] Click "Find Next"
- [ ] Word should highlight the placeholder

### Step 2: Delete Old Placeholder
- [ ] Click **BEFORE** the first `{` character
- [ ] Hold `Shift` and click **AFTER** the last `}` character
- [ ] This selects: `{{tanggal}}`
- [ ] Press `Delete` key
- [ ] Placeholder should disappear

### Step 3: Type New Placeholder
- [ ] Type these 12 characters **WITHOUT STOPPING**:
  ```
  { { t a n g g a l } }
  ```
- [ ] Result should look like: `{{tanggal}}`
- [ ] **IMPORTANT:** Don't pause, don't go back, type once through

### Step 4: Clear Formatting
- [ ] Click **BEFORE** the first `{`
- [ ] Hold `Shift` and click **AFTER** the last `}`
- [ ] This selects: `{{tanggal}}`
- [ ] Press `Ctrl+Space` (clear character formatting)
- [ ] Placeholder should NOT change appearance

### Step 5: Verify
- [ ] Click in the middle of `{{tanggal}}`
- [ ] Look at Word toolbar (top):
  - Font should be same as surrounding text
  - Size should be same as surrounding text
  - No Bold, Italic, Underline
- [ ] Select placeholder again
- [ ] Press `Ctrl+Space` one more time
- [ ] Placeholder should NOT change
- [ ] **If it changes = NOT fixed yet, go back to Step 2**

## ❌ Troubleshooting

### Problem: Ctrl+Space changes placeholder appearance
**Cause:** Placeholder still has formatting  
**Solution:** 
1. Delete placeholder completely
2. Retype from scratch
3. Make sure to type in ONE GO without pausing

### Problem: Can't find placeholder with Ctrl+F
**Cause:** Placeholder might have invisible characters  
**Solution:**
1. Scroll through document manually
2. Look for `{{tanggal}}` or `{{nama1}}`
3. Select and delete when found

### Problem: Upload fails
**Cause:** File might be corrupted or too large  
**Solution:**
1. Save as new file: "Template - Fixed.docx"
2. Try upload again
3. If still fails, create new document and copy content

### Problem: Still get 26 errors after fix
**Cause:** One or both placeholders not fixed properly  
**Solution:**
1. Re-open template
2. Test each placeholder with Ctrl+Space
3. If placeholder changes = not fixed
4. Repeat fix steps more carefully

### Problem: Placeholder changes color when Ctrl+Space
**Cause:** Formatting still embedded in placeholder  
**Solution:**
1. DON'T try to "fix" the formatting
2. DELETE the entire placeholder
3. RETYPE from scratch
4. Remember: Type in ONE GO
